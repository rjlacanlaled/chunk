| File | Description |
|---|---|
| chunk-logo-horizontal-light.svg | Primary horizontal lockup (light bg) |
| chunk-logo-horizontal-dark.svg | Horizontal lockup (dark bg) |
| chunk-logo-stacked.svg | Stacked icon + wordmark |
| chunk-icon-80.svg | App icon 80px |
| chunk-icon-40.svg | App icon 40px |

## Strapi Color Tokens

| Token | Hex | Usage |
|---|---|---|
| Blue 600 | #4945FF | Primary — main icon fill |
| Blue 900 | #271FE0 | Dark blue variant |
| Purple 500 | #9736E8 | Purple variant |
| Green 500 | #5CB176 | Green variant |
| Yellow 500 | #F5CF0D | Yellow variant |
| Neutral 900 | #32324D | Wordmark text (light bg) |

## Usage Notes
- Use **Blue 600 (#4945FF)** as the primary brand color
- On dark backgrounds, wordmark text switches to white
- Yellow variant requires dark (#32324D) bars instead of white for contrast
- SVG files are infinitely scalable — use at any size
