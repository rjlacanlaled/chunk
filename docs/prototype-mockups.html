Summary
Design Decisions
  • Chat-first architecture: The empty state opens directly to a chat prompt instead of a dashboard. This lowers the barrier to entry — users don't need to learn a UI, they just talk.
  • 70/30 split layout: Tasks take the majority of screen space since that's the primary output, but the chat stays persistently visible to maintain context. No modal or route switching needed.
  • Mobile tab navigation: On smaller screens, side-by-side doesn't work. A bottom tab bar lets users switch between Tasks and Chat without losing state in either view.
  • Gamification as motivation, not distraction: XP, streaks, and medals are visible but not intrusive. They sit in the header and a dedicated section rather than cluttering the task list.
  • Score-based difficulty dots: A simple colored dot next to each task communicates difficulty at a glance (green = easy, yellow = medium, red = hard) without adding visual noise.
  • AI tool feedback: When Chunky performs actions like creating tasks, a tool chip appears in the chat so users understand what happened behind the scenes.
  • Dark mode default: Reduces eye strain for long productivity sessions and matches the modern aesthetic expected by the target audience.
