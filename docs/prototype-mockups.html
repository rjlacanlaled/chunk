Summary
Design Decisions
  1. Chat-first — natural language over form fields
  2. Auto-breakdown — tasks scoring 20+ split automatically
  3. Guest-first — zero friction, sign up later
  4. Recursive hierarchy — real projects have depth
  5. Gamification — XP and streaks make completing tasks feel good
  6. AI-driven scoring — users never pick difficulty manually
  7. Responsive design — tab-based on mobile, side-by-side on desktop
