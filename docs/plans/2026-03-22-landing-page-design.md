# Landing Page Design

## Route Structure
- `/` — Landing page (public)
- `/dashboard` — App (chat + tasks + gamification)

## Sections

### 1. Hero
- Headline: "Your to-do app is broken. Chunky fixed it."
- Subheadline: "Meet Chunky — your AI productivity buddy that turns brain dumps into game plans."
- Large Chunky mascot (animated SVG when available, idle variant for now)
- CTA: "Start chunking — it's free" → links to /dashboard
- Secondary: "See how it works" → scrolls to section 4
- Micro-line: "No sign-up required. Start in 3 seconds."

### 2. Tech Credibility Strip
- "Built with" + logos: Next.js, Supabase, Vercel, OpenRouter, Drizzle, TanStack Query

### 3. The Problem
- Eyebrow: "The productivity trap"
- Headline: "Your to-do list is lying to you."
- Body: Short anti-procrastination copy
- Transition: "Chunk does things differently."

### 4. How It Works
- Eyebrow: "How Chunk works"
- Headline: "Chat it. Chunk it. Crush it."
- Three steps with icons/animations

### 5. Product Showcase
- Live mini-preview components rendered inline
- Chat interface preview, task cards, XP bar

### 6. Features Grid (2x3)
- Chat-First AI, Auto-Chunking, XP & Levels, Streaks, Smart Scoring, Zero Friction

### 7. Gamification Showcase
- Headline: "Finally, a reason to finish things."
- Medal progression (designer's SVGs)
- XP/streak/confetti callouts

### 8. Personality Showcase
- Example Chunky conversations (chat mockup)

### 9. Tech Stack
- Headline: "Built with modern tools. Built to last."
- Tech logo strip

### 10. Final CTA
- Headline: "Your tasks aren't going to chunk themselves."
- Big CTA button

### 11. Footer
- Chunk logo, GitHub link, OPIT credit

## Visual Design
- Background: #1C1C4E (Strapi Dark Blue)
- Accent: #4945FF (Strapi Blue)
- Secondary: #9593FF (Light Blue)
- Font: Poppins
- Radius: 5px
- Subtle glow effects, gradient meshes
- Dark mode only
